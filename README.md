## 🌟 Key Features
* **Automated Data Extraction**: Extracts complex numerical data and metadata directly from PDFs with high accuracy using Agentic AI workflows.
* **Meta-Analysis Integration**: Seamlessly formats extracted data for immediate analysis in statistical software like JASP.
* **Manuscript Auditor**: Built-in AI auditor that ensures academic rigor, removes AI-generated stylistic patterns, and strictly follows PRISMA 2020 guidelines.
* **End-to-End Pipeline**: 16-stage autonomous pipeline replacing hundreds of hours of manual screening, data cleaning, and synthesis.

## 📊 How It Works
1. **Input**: Feed the system your screened PDFs.
2. **Process**: The AI Agent orchestrates extraction, cleaning, and statistical preparation autonomously.
3. **Output**: Get a ready-to-audit, Q1/Q2 journal-compliant manuscript draft.
